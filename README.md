⛪ Projeto Web: Igreja Canaã

🎯 Sobre o Projeto
Este site foi desenvolvido como um portal informativo para a Igreja Canaã. 
O objetivo do trabalho é aplicar conceitos de desenvolvimento web para criar uma interface acessível, 
que facilite o acesso de membros e visitantes a informações essenciais como horários de cultos, localização e eventos da comunidade.


🛠️ Tecnologias
O site foi construído utilizando as tecnologias base da web:

HTML: Utilizado para estruturar todo o conteúdo da página.

CSS: Utilizado para o design, cores e para tornar o site adaptável a celulares (responsivo).

JavaScript: Utilizado para adicionar funcionalidades e interatividade ao site.

🚀 Funcionalidades
Design Responsivo: O site funciona bem em computadores e celulares.

Informações de Culto: Exibição clara de horários e programações.

Seção de Contato: Facilita o acesso ao endereço e localização.
