# ⛪ Projeto Web: Igreja Canaã

## 🎯 Sobre o Projeto
Este site foi desenvolvido como um portal informativo para a Igreja Canaã, aplicando conceitos de desenvolvimento web para criar uma interface acessível que facilite o acesso de membros e visitantes a horários de cultos, localização e eventos.

## 🛠️ Tecnologias
* **HTML:** Estruturação do conteúdo.
* **CSS:** Design responsivo e estilização visual.
* **JavaScript:** Funcionalidades e interatividade.

## 🚀 Funcionalidades
* **Design Responsivo:** Adaptado para computadores e dispositivos móveis.
* **Informações de Culto:** Exibição clara de horários e programações.
* **Seção de Contato:** Acesso rápido ao endereço e localização.
